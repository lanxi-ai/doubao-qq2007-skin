# 豆包皮肤·QQ2007版

为豆包网页版添加 QQ 2007 风格的怀旧界面、头像资料卡、本机娱乐等级和回复提示。扩展使用 Manifest V3，无构建步骤或第三方运行时依赖。

本项目为独立的非官方作品，与豆包、字节跳动、QQ 或腾讯不存在官方隶属、合作或认可关系。等级只在当前浏览器内累计，不是 QQ 账号等级，不修改豆包或 QQ 账号权益。

## 版本与适用范围

- 本目录源码版本：`0.2.3`，以根目录 `manifest.json` 为准。
- 浏览器：Chrome 120 及以上。
- 作用页面：`https://www.doubao.com/chat/*` 和 `https://doubao.com/chat/*`。
- [Chrome 网上应用店项目](https://chromewebstore.google.com/detail/hpninknmgimbfdaljmdomjbgbnibbdgc)
- 商店扩展 ID：`hpninknmgimbfdaljmdomjbgbnibbdgc`。

上述版本描述本目录源码，不代表商店当前可用版本或审核状态。

## 功能

- 晴空蓝、日光金、薄荷绿三种配色，随本机等级解锁，可自动换肤或手动选择。
- 正式模式每累计 30 分钟升一级，使用星星、月亮、太阳和皇冠显示等级；打开目标网站标签页即可累计，后台标签页也算，锁屏时暂停。关闭皮肤只关闭界面效果，不停止符合条件的等级累计。
- 独立测试模式，每 30 秒升一级，可手动升一级或重置测试进度，不清除正式累计时长。
- 内置头像选择、本机图片头像、自定义昵称、签名与显示状态。
- 气泡、字体、字号、配色收藏，表情及颜文字插入；表情由用户自行发送。
- 回复完成提示音、升级音效及动画、回复完成后的五分钟未回复提醒。继续输入会延后提醒，发送下一条消息或离开对话会取消本轮提醒。
- 可关闭怀旧界面，并从浏览器工具栏的扩展设置重新开启。

回复识别和页面布局依赖豆包网页结构；网站更新后可能需要适配。浏览器声音策略可能要求先点击网页或使用“试听回复音”。

## 本地加载

1. 将源码保存到独立文件夹，确认该文件夹根目录直接包含 `manifest.json`。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开 [豆包聊天页面](https://www.doubao.com/chat/)，按网站要求登录；已打开的页面请刷新。
5. 点击网页面板或浏览器工具栏图标调整设置。修改源码后，在扩展管理页面点击“重新加载”，再刷新目标网页。

无需执行 `npm install`。本地加载版可能与商店版使用不同扩展 ID，因此等级、头像和设置不会自动共享。验证本地版本时，可先暂时停用商店版，避免两个版本同时修改同一网页。

## 本地数据与权限

扩展通过 `chrome.storage.local` 保存头像、昵称、签名、显示状态、等级进度和界面/声音偏好；通过 `chrome.storage.session` 保存临时计时检查点，不使用 `storage.sync`。

为实现计时、回复提示和表情插入，扩展还会在内存中处理匹配页面的 URL/会话路径、消息标识与生成状态、输入事件时间、光标或选区等信息。当前代码不保存聊天正文，不逐字记录键盘输入，没有开发者服务器、广告或统计服务，也没有将这些数据主动上传给开发者的实现。仅在本机处理不等于完全不处理用户数据。

资料和头像会显示在网页的开放 Shadow DOM 中，网页脚本在技术上可能访问显示值。豆包网站本身的数据处理仍由该网站负责。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本机资料、进度与偏好，保存会话计时检查点 |
| `alarms` | 每 30 秒唤醒后台检查累计时长 |
| `idle` | 读取设备活动状态，以锁屏状态暂停累计 |
| 豆包网站权限 | 注入界面、读取功能所需页面标记、插入表情并判断目标标签页是否打开 |

“重置测试”只清除测试进度。关闭皮肤或禁用扩展不会清除已保存数据；卸载扩展会清除该扩展的本地存储，不会删除原始头像图片或网站聊天记录。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `manifest.json` | 扩展名称、版本、权限、脚本及资源入口 |
| `background.js`、`core.js` | 后台消息、计时、等级和配色解锁 |
| `content.js`、`site-adapter.js`、`theme.css` | 网页布局适配、面板挂载与怀旧样式 |
| `panel.js`、`popup.html`、`popup.js`、`popup.css` | 网页面板和工具栏设置 |
| `avatars.js`、`avatar-catalog.js`、`profile.js` | 头像与本机资料 |
| `decor.js`、`retro-icons.js` | 装扮、表情插入和等级图标 |
| `reply-watch.js`、`feedback.js`、`nudge.js` | 回复状态识别、音效和未回复提醒 |
| `assets/` | 随扩展打包的图像、音频和资源来源记录 |
| `头像来源说明.md`、`声音来源说明.md` | 第三方素材来源说明 |
